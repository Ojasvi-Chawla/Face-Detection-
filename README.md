# Face-Detection-
A computer vision project that detects human faces in images using OpenCV and Python. This project demonstrates the implementation of real-time face detection using pre-trained Haar Cascade classifiers.

📌 Project Overview :

This project focuses on detecting faces from images or live webcam video using OpenCV’s Haar Cascade algorithm. It is a beginner-friendly computer vision project that introduces the fundamentals of image processing and object detection.
The system identifies faces in real-time and highlights them with bounding boxes.

🎯 Objectives :
To understand the basics of computer vision
To implement face detection using OpenCV
To process images and video frames in real-time
To detect and highlight faces accurately

🚀 Features :
Real-time face detection using webcam
Face detection on static images
Uses Haar Cascade Classifier
Simple and lightweight implementation
Fast processing with OpenCV
